# joestilllives.github.io

Personal site of Rahul Gupta (Joe), served by GitHub Pages at <https://joestilllives.github.io>.

| Path | What it is |
| --- | --- |
| `/` | Portfolio: skills, projects, contact links. Originally built on [CodePen](https://codepen.io/JoeStillLives/pen/jddqQb). |
| [`/tilt/`](https://joestilllives.github.io/tilt/) | **Tilt**: tilt your phone to change the note, touch to play it, shake for a drum. Installable web app. |
| [`/buddy/`](https://joestilllives.github.io/buddy/) | **Pip**: a pocket buddy that saves voice notes in English and Hindi. Installable web app. |
| [`/aqi/`](https://joestilllives.github.io/aqi/) | **Clear Air Check**: India's official AQI compared with independent sources, all on the Indian AQI scale. |
| [`/patents/`](https://joestilllives.github.io/patents/) | **Second Chance Patents**: expired patents re-imagined for underprivileged communities, with the BigQuery queries used to find them. |
| [`/carryover/`](https://joestilllives.github.io/carryover/) | **Carryover**: exports Microsoft To Do lists (retiring 30 June 2027) for Todoist, Notion, Obsidian, spreadsheets and calendar apps. Runs in the browser with read-only Microsoft sign-in; add the app registration\'s client ID in `carryover/app.js` to enable sign-in (demo mode until then). |
| [`/tokri/`](https://joestilllives.github.io/tokri/) | **Tokri**: free tool that turns a menu into a WhatsApp order link and printable QR poster. The menu is stored in the link itself, so there is no server. Bundles [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT). |
| [`/services/`](https://joestilllives.github.io/services/) | **Websites for local businesses**: what I offer, pricing, and links to the sample sites. |
| [`/demos/`](https://joestilllives.github.io/demos/clinic/) | Sample sites for made-up businesses (clinic, coaching centre, home bakery) and a WhatsApp-style AI assistant demo (`/demos/assistant/`), linked from `/services/`. |

Everything is plain HTML, CSS and JavaScript with no build step. Push to `master` and Pages publishes it.
