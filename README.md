# joestilllives.github.io

Personal site of Rahul Gupta (Joe), served by GitHub Pages at <https://joestilllives.github.io>.

| Path | What it is |
| --- | --- |
| `/` | Portfolio: skills, CodePen projects, contact links. Originally built on [CodePen](https://codepen.io/JoeStillLives/pen/jddqQb). |
| [`/tilt/`](https://joestilllives.github.io/tilt/) | **Tilt**: tilt your phone to change the note, touch to play it, shake for a drum. Installable web app. |
| [`/buddy/`](https://joestilllives.github.io/buddy/) | **Pip**: a pocket buddy that saves voice notes in English and Hindi. Installable web app. |

Everything is plain HTML, CSS and JavaScript with no build step. Push to `master` and Pages publishes it.
