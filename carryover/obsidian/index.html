How to move from Microsoft To Do to Obsidian

Obsidian works with plain Markdown files. Carryover turns every To Do list into a heading with a checklist underneath.

Short answer: Export with Carryover using the Markdown format, then move the file into your Obsidian vault folder. It opens as a normal note with checkboxes.

Step by step

  1. Export from To Do

    Open the Carryover tool, sign in, choose Obsidian and notes apps and download carryover-tasks.md.

  2. Find your vault folder

    In Obsidian, right-click any folder in the file list and choose to show it in your file manager.

  3. Move the file in

    Put carryover-tasks.md into the vault. Obsidian picks it up straight away.

  4. Split it up if you like

    Each list is a ## heading, so you can cut lists into separate notes.

What carries over

In To DoIn the Markdown file
ListA heading
TaskA checkbox line: - [ ] Renew passport
Completed task- [x], if you include completed tasks
StepsNested checkboxes under the task
Due date, repeat, importanceIn brackets after the title: (due 2027-01-15, important)
NotesA quote block under the task

The same file works in Logseq, Joplin, Bear, Typora and most notes apps that read Markdown.

Questions

Does it work with the Obsidian Tasks plugin?

The checkboxes do. Due dates are written in plain words, so the plugin will not read them as dates until you change them to its format.

Is Carryover safe?

It asks Microsoft only for permission to read your tasks. Your lists go from Microsoft straight into your browser and the file you download. There is no Carryover server, and the code is public on GitHub.
