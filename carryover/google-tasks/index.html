Moving from Microsoft To Do to Google Tasks

Google Tasks is simple and free, but it has no way to import a file. Here is what you can do today.

Short answer: Google Tasks has no import option, so no file can move your lists into it directly. Keep a full backup with Carryover now. A direct transfer from Carryover that sends tasks straight to Google Tasks is planned; until then, small lists are quickest to retype.

Step by step

  1. Back up now

    Download the JSON backup and the spreadsheet from the Carryover tool, so nothing is lost whatever you decide.

  2. Small lists: retype

    For a few dozen tasks, open the spreadsheet beside Google Tasks and add them by hand.

  3. Large lists: wait for direct transfer

    Carryover’s direct transfer will sign in to Google with your permission and create your lists and tasks for you. It is planned and will be announced on this page.

  4. Or choose an app that can import

    If you want everything moved in minutes, Todoist, Notion and Obsidian can all import Carryover’s files.

Questions

Why can’t I just import a CSV?

Google has never added an import option to Google Tasks. Only apps that use its API, like Carryover’s upcoming transfer, can add tasks in bulk.

Will the direct transfer be free?

Yes, like the rest of Carryover.

Is Carryover safe?

It asks Microsoft only for permission to read your tasks. Your lists go from Microsoft straight into your browser and the file you download. There is no Carryover server, and the code is public on GitHub.
