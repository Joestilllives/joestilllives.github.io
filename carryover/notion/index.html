How to move from Microsoft To Do to Notion

Notion turns a CSV file into a database. Carryover exports all your To Do lists into one spreadsheet that Notion imports cleanly.

Short answer: Export with Carryover using the “Notion, Excel, Sheets” format. In Notion, choose Import, then CSV, and pick the file. Every task becomes a row you can filter, sort and group by list.

Step by step

  1. Export from To Do

    Open the Carryover tool, sign in, choose Notion, Excel, Sheets and download carryover-all-tasks.csv.

  2. Import into Notion

    In Notion, open Import (in the sidebar, or under Settings) and choose CSV. Pick the file.

  3. Tidy the columns

    Change Due date to a Date property and List to a Select property. You can change Done to a Checkbox.

  4. Make a board

    Add a Board view grouped by List to get something that looks like To Do’s lists.

Notion imports the whole file as one database. If you prefer one database per list, filter by List and duplicate the view, or export only one list at a time.

Questions

Do steps become sub-items?

They come in as text in the Steps column, one per line. Notion has no CSV option for sub-items.

Will reminders work in Notion?

The reminder time is kept as text. Add a Notion reminder to the Due date property if you need one.

Is Carryover safe?

It asks Microsoft only for permission to read your tasks. Your lists go from Microsoft straight into your browser and the file you download. There is no Carryover server, and the code is public on GitHub.
