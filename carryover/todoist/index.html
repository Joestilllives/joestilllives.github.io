How to move from Microsoft To Do to Todoist

Todoist can import tasks from a CSV file. Carryover makes one file per To Do list in the format Todoist expects.

Short answer: Export with Carryover using the Todoist format. You get a zip with one CSV per list. In Todoist, create a project for each list and import its file from the project menu.

Step by step

  1. Export from To Do

    Open the Carryover tool, sign in, choose Todoist and download. You get a file called carryover-todoist.zip.

  2. Unzip it

    Inside is a todoist folder with one CSV per list, for example Groceries.csv.

  3. Create a project in Todoist

    Make one project per list, using the list’s name.

  4. Import the file

    Open the project, open its menu (the three dots next to the name) and choose Import from CSV. Pick that list’s file. Import works in Todoist on the web and on desktop.

  5. Check and repeat

    Your tasks appear in the project. Repeat for each list.

Menu names in Todoist can change between versions. If you can’t find Import from CSV, search Todoist’s help centre for “import from CSV”.

Questions

Can I import all lists at once?

Todoist imports one CSV into one project, so Carryover makes one file per list. With a handful of lists it takes a few minutes.

My repeating task looks wrong

Todoist reads the repeat as plain English. If one doesn’t match, edit its date in Todoist, for example to “every Monday”.

Will my steps stay under their task?

Yes. Steps are imported as sub-tasks directly under the task they belonged to.

Is Carryover safe?

It asks Microsoft only for permission to read your tasks. Your lists go from Microsoft straight into your browser and the file you download. There is no Carryover server, and the code is public on GitHub.
