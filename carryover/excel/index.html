How to export Microsoft To Do to Excel or Google Sheets

A spreadsheet is the simplest copy of your tasks: easy to read, sort, print or move anywhere later.

Short answer: Export with Carryover using the “Notion, Excel, Sheets” format. Open the CSV in Excel directly, or import it into Google Sheets.

Step by step

  1. Export from To Do

    Open the Carryover tool, sign in, choose Notion, Excel, Sheets and download carryover-all-tasks.csv.

  2. Excel

    Double-click the file. Text in any language, including Hindi, opens correctly.

  3. Google Sheets

    Create a sheet, then choose File, Import, Upload and pick the file.

  4. Sort and filter

    Turn on filters and sort by List or Due date.

Tasks whose titles begin with =, + or @ get a leading apostrophe in the spreadsheet so they are shown as text, not run as formulas.

Questions

Can I import this spreadsheet into another app later?

Yes. Most task apps and databases can import CSV, and the JSON backup keeps every detail if you need more.

Is Carryover safe?

It asks Microsoft only for permission to read your tasks. Your lists go from Microsoft straight into your browser and the file you download. There is no Carryover server, and the code is public on GitHub.
